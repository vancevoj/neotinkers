# Neo Tinkers'

An unofficial **Minecraft NeoForge** port of **Tinkers' Construct**. This port is an actively maintained project to keep Tinkers' Construct up-to-date with the latest Minecraft versions!

Full content credit for the mod goes to SlimeKnights. I take no credit for any of the original work. This project is in no way endorsed by or affiliated with SlimeKnights.

**Requires [Neo Mantle](https://github.com/vancevoj/neomantle)**: the port of Mantle, a dependency mod. Install it alongside this one.

## Download

Pick your Minecraft version and download **both jars** (Neo Tinkers' and Neo Mantle) from that version only. Jars from different versions do not mix.

### Minecraft 1.21.1

Needs NeoForge 21.1 and Java 21.

| Mod | Version | Download |
|---|---|---|
